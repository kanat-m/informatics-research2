# Master's Research: AI in Secondary Education Quality Management

Code and materials for my Master's research focused on applying Artificial Intelligence to manage and improve quality in secondary education.

## 🔬 Research Focus
- Integration of AI tools in educational monitoring and assessment
- Full-stack development of educational platforms
- Data analysis and machine learning applications for school systems

## 🛠️ Tech Stack
- **Frontend / Backend:** Python, FastAPI, Next.js
- **Database:** PostgreSQL
- **DevOps:** Docker, GitHub Actions
